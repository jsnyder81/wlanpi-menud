## Should-fix (non-blocking)

- **F1: no offline test drives the `complications.2` path through the panel.** `FakeMenud(features=...)` was added, but no test passes it. `test_live_menud` accepts either 4 or 7 topic snapshots, so it passes whether or not the new topics are subscribed. Replacing the feature branch with `if False:` leaves all 175 tests green. Add a `test_panel.py` case with `features=["complications.2"]` that checks the subscribe list, the strip order from `complications.config`, and a repaint after a config event.
- **F2: build the deb at `637d37f`** and confirm that `complications.py` and `glyphs.py` are in the payload before the device trial.
- **S2/S3 (carried over):** fix the "thin rule lines" claim and explain the bundled changes. Give `5b8f56d` a body that names the kv `level`, the list tags and rule, and the client `features` handling.
- **menud side (not this branch):** `demo/serve_fake.py` doesn't override `complications_user_file`, so it keeps the default `/var/lib/wlanpi-menud/complications.json`. A live test or a developer who uses Home tiles against it would try to write the host's `/var/lib`. Point it at the temp sockdir.

## Minor

- m1: `STRIP_MAX_SLOTS = 3` (`complications.py:28`), `complications[:3]` and `sx = 38 + i * 30` (`render.py`) are all hard-coded. Derive them from `COLS` with the §4.5 formula so the three can't drift apart.
- m2: the mono check is `THEME.__name__ == "BlackAndWhiteTheme"`, a string compare. Prefer an attribute on the theme.
- m3: the new topics are appended to `client.topics` permanently. After a downgrade to an old service, the client still subscribes to them and gets `data: null`. That's harmless because the feature gate decides use, but it adds noise.
- m4: the strip falls back to text (`short`, then `value[:4]`, then `label[:4]`) and draws the `icon` only when that text is empty. This is consistent with §4.6, but icons will almost never show. Fine for now.
- Carried over from the re-review: the ASCII classifier is tied to DarkTheme RGB values; `if topic_schema:` would skip silently if the def disappeared.
